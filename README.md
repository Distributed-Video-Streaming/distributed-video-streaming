# Sprint 1 Architecture Deliverables

This folder contains a draft architecture document and proposed Architecture Decision Records (ADRs) for a video system using a JavaScript client, C++ backend, and proxy.

## Files
- `docs/architecture.md` — high-level design, component responsibilities, data flow, candidate protocols, and checklist.
- `docs/adr/ADR-0001-client-backend-boundaries.md` — proposed responsibility boundaries.
- `docs/adr/ADR-0002-communication-protocols.md` — proposed communication protocol principles.
- `docs/adr/ADR-TEMPLATE.md` — template for recording future decisions.

## Before merging
These documents are **draft proposals**, not verified descriptions of the implementation. Review them with the C++ Backend and JavaScript Client teams. Replace assumptions with facts from the code and requirements, especially the proxy's location, the video source, and the actual data path.
